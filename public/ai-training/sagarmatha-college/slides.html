What is Git?

Git = save points for your whole project

  • Like saving in a game: you can always go back to an earlier save.
  • A folder Git tracks is a repository. Each save point is a commit: your files, a short message, your name and the time.
  • Runs on your laptop. Works offline. Free and open source.
$ git log --oneline a3f9c21 Fix scanf bug in sum program 7be4d10 Add loop for sum of 1 to n 51c0e8a Print welcome message 0d2b9f3 First commit: hello world # Every line is a save point. # Every save point has a message. # You can return to any of them.

Keep it concrete. "A commit is a photograph of your whole project at one moment, with a caption written by you."

Emphasise the message: "Fix scanf bug" tells future-you what happened. "asdf" does not.

The most common confusion

Git ≠ GitHub

The tool

Git

  • Software on your laptop
  • Tracks every change
  • Works offline
  • Like the camera

The website

GitHub

  • Hosts your Git projects online
  • Backup, sharing and group work
  • More than 100 million developers, owned by Microsoft
  • Like the online photo album where others can see and comment

Alternatives to GitHub: GitLab, Bitbucket, Codeberg. They all speak Git.

Say: "Git is the camera. GitHub is the online album. You can take photos without uploading them, but uploading means they're backed up and your friends can see and comment."

Microsoft bought GitHub in 2018. If anyone asks: yes, you can use Git with no GitHub at all.

No more zip files on Messenger. Everyone's work, merged and backed up.

How it fits together

The loop you'll use every day

Add = choose what goes in the box · Commit = seal it with a label · Push = ship it online

Walk left to right. The analogy: packing a parcel. You add items to the box, commit seals it with a label, push sends it to GitHub. Pull brings your teammates' parcels back to you.

Why the staging area? "Because sometimes you changed five files but only three belong in this save."

Enough for your whole first year

Seven commands

git init # start tracking this folder git clone <url> # copy a repo from GitHub git status # what changed? git add lab3.c # put it in the box git commit -m "Fix loop" # seal with a message git push # send to GitHub git pull # get the latest

Commit messages

Good  Add input check to calculator

Good  Fix sum loop stopping early

Bad  update

Bad  asdfgh

Bad  final final final

Rule: finish the sentence "This commit will…"

Don't teach every flag. "These seven cover 95% of what you'll do this year. git status is your best friend: run it whenever you're confused."

Mention: install Git from git-scm.com, or use VS Code, which has Git built in.

Live demo · watch first, then you do it

One full loop: laptop to GitHub

  1. Create an empty repository on GitHub: my-first-website
  2. Make a folder with an index.html
  3. git init → git add → git commit
  4. git push, then refresh GitHub: the file is there
  5. Change one line, commit and push again. Open History: red = removed, green = added
$ mkdir my-first-website $ cd my-first-website $ echo "<h1>Namaste!</h1>" > index.html $ git init $ git add index.html $ git commit -m "Add my first webpage" $ git remote add origin <your repo URL> $ git push -u origin main

Do this live in a terminal on the projector, slowly, saying each command's job out loud. It's exactly what they do in Exercise 1.

Second commit: change the heading to "Namaste, BCA and CSIT 2026!", then git add, git commit -m "Update greeting", git push. Open the commit on GitHub and show the red and green lines.

Backup if the Wi-Fi fails: do steps 2–3 (they work offline) and explain that push needs the internet. That's the Git vs GitHub point again.

Order matters: install Git first (macOS xcode-select --install downloads for 5–15 minutes, so Mac users start it first and create their GitHub account while it downloads), then the GitHub account, then the SSH key that connects the two.

What is AI, really?

Programs that learn from examples, not from rules we write

Old way: rules

if message contains "lottery" → spam
Breaks as soon as scammers change one word.

AI way: examples

Show it a million messages marked "spam" or "not spam". It works out the pattern by itself.

You already use it every day

  • Spam going straight to your Gmail spam folder
  • The next video TikTok or YouTube picks for you
  • Face unlock on your phone
  • Google Maps showing traffic in Koteshwor
  • ChatGPT, Gemini, Claude: AI that writes

Ask: "Who has used AI today?" Few hands. Then point at the list: "All of you. Face unlock, your feed, your spam folder." AI isn't new; AI that writes and talks is what's new.

Part 3

Treat AI like
a person

3

This is the most practical part. Energy up.

The mindset

Treat AI like a person who knows nothing about you

1

It starts at zero

It doesn't know your course, your level, your deadline or what your teacher wants.

2

You tell it

Who to be: "Act as my C tutor." Who you are, and what you need.

3

It holds it, and plays the part

For the rest of this chat it remembers what you said and answers as that person. A new chat starts at zero again.

Whatever you don't tell it, it guesses. Whatever you tell it, it uses.

"Imagine a very smart person joins your group project today. They know nothing about you. Tell them the topic, the marking scheme and who reads it, and they'll work as your teammate for the rest of the project. Say nothing, and they'll guess."

Giving AI a role is the same idea: "Act as my C tutor" tells it who to be, and it holds that role, plus everything you told it, until the chat ends. That's why the next slide, TEACH, is a checklist of what to tell it.

Five things to tell AI

TEACH

TTaskWhat exactly should it do?Explain pointers
EExpectationWhat does good look like? What must it never do?<250 words, never skip * vs &
AAudienceWho reads it, and what do they know?1st-year BCA / CSIT student
CContextWhat can it not possibly guess?Exam in 3 days, confused by *p
HHowWhat shape should it come back in?Analogy → code → 3 questions

Answer all five and you get a strong prompt. Skip one and AI guesses.

Module 2, video 2. Have the class say it aloud: "Task, Expectation, Audience, Context, How."

The most-skipped letter is C, the context it can't guess. The most powerful part of E is the "never" rule.

TEACH in action · same question, two prompts

Lazy vs clear

Lazy
explain pointers in c

You get: a long, textbook-style answer that isn't written for you.

Clear (TEACH)
Act as a patient C programming tutor. Task: Explain pointers in C. Expectation: Under 250 words, one everyday analogy. Never skip the difference between * and &. Audience: A first-year BSc CSIT / BCA student who knows variables and arrays but has never used pointers. Context: My exam is in 3 days and I keep mixing up *p and &x. How: Analogy first, then a 10-line commented example, then 3 quick questions to test me, with answers at the end. If anything is unclear, ask me before you start.

Live demo (2 min): run both in the same AI tool, side by side. Copy the TEACH version with the Copy button.

Point out what changed: the length is controlled, there's an analogy (often a house address), the level is right, and it ends by testing you.

In a hurry? Remember AAA

Ask AI to Ask

Don't know what to write? Let AI ask you questions first, so it stops guessing.

Learning

"I want to learn recursion. Before you explain, ask me 3 questions about what I already know."

A project

"Help me plan a website for my uncle's shop. Ask me questions one at a time until you understand what he needs."

Writing

"I need an email to my teacher. Ask me what you need to know before you write it."

Got time? Use TEACH. In a hurry? Ask AI to Ask, and answer its questions.

The shortcut when they can't be bothered to write a full TEACH prompt: AI asks for the missing letters itself. Have the class say it: "Ask AI to Ask."

Point back: "The clear prompt you just saw ended with 'If anything is unclear, ask me before you start.' That line is AAA."

Ask: "What else could you ask AI to ask you about?" Good answers: my CV, my project idea, a hard assignment question.

For students specifically

Use AI as a tutor, not an answer machine

I'm a first-year [BSc CSIT / BCA] student learning [TOPIC]. Don't give me the answer. Teach me by asking me questions: ask me one question at a time, wait for my reply, give a hint if I'm stuck, and only confirm the answer once I've reasoned it out myself. At the end, give me 3 practice problems slightly harder than this one.

A tutor that's free, patient at 2 a.m., and never judges your "basic" question. But only if you do the thinking.

This is the single most valuable prompt for first-years. Tell them to save it.

Why it matters: "If AI always does the thinking, you never learn to do it, and first year is when you learn. Exams and interviews don't come with a chatbot." Then bridge to Part 4: "Using AI well also means using it safely."

Use it safely
and honestly

4

Confidently wrong

A made-up answer looks exactly like a true one

About Nepal

Asked which article of the Constitution of Nepal gives the right to information, an AI confidently said Article 32.

It's Article 27.

In code: fake packages

AI sometimes suggests software packages that don't exist. Attackers then publish packages with those exact names, with harmful code inside.

Copy the pip install line, and you install the attacker's code.

Check the real source. The official website, your textbook, the real package page. Asking AI "are you sure?" is not checking.

The first example comes from Module 4, video 3. The second is a real and growing security problem: researchers have shown LLMs invent package names, and attackers register those names on PyPI and npm. The term is "slopsquatting".

CS hook: "Before installing any package AI suggests, check it on pypi.org or npmjs.com: download count, last update, real GitHub repo."

Before you paste anything into AI · 1 finger green, 2 amber, 3 red

Ask: "If this leaked, who gets hurt?"

Green · nobody. Use it.

Amber · someone. Hide names and numbers first.

Red · can't hide it. Never paste it.

Explain the three colours in 30 seconds, then play: students show 1, 2 or 3 fingers for each card, then tap to reveal.

Also tell them: turn off "use my chats for training" in every AI app. ChatGPT → Settings → Data controls; Gemini → Activity; Claude → Privacy. Check the current menu paths before the session.

The API key card is the CS-specific one. Real story to tell: bots scan public GitHub repos for keys within minutes. That links back to Part 1. Use a .env file and .gitignore.

After the game · AI or Not?

What gave them away, and why that won't last

Writing

Signs and number plates. AI often garbles letters, especially Devanagari, but newer AI gets it right.

Counting

Fingers, fork prongs, railings. The shape looks right, the number is wrong.

Too perfect

Identical momos, golden light everywhere, a crowd with no one mid-step.

Voices and calls too

A few seconds of audio can copy a voice. Urgent + secret + new number = scam. Call back.

The class called – of the AI images "real". The best fakes show no clues at all. Check where a photo came from, not just how it looks.
