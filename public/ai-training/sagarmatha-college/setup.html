Set up Git

About 10 minutes. Pick your computer, fill in your details once, then copy each command into your terminal.

Use the same email as your GitHub account.

Your GitHub username comes from step 4. The commands below update as you type.

1

Install Git

Open PowerShell: press the Windows key, type PowerShell, press Enter. Then run:

winget install --id Git.Git -e --source winget

Type Y if it asks you to agree. When it finishes, close PowerShell and open Git Bash from the Start menu. Type every command on this page into Git Bash.

"winget is not recognized"? Your Windows is older: download the installer from git-scm.com instead and click Next on every screen.

Open Terminal: press Cmd + Space, type Terminal, press Enter. Then run:

xcode-select --install

A window pops up. Click Install (not "Get Xcode") and wait 5 to 15 minutes.

Already use Homebrew? brew install git works too.

Open a terminal (usually Ctrl + Alt + T) and run the line for your system. It asks for your computer password. Nothing shows while you type it; that's normal.

Ubuntu, Debian, Linux Mint

sudo apt update && sudo apt install -y git

Fedora

sudo dnf install -y git

Arch, Manjaro

sudo pacman -S git
2

Check it worked

Close the Git Bashterminal window, open a new one, and run:

git --version

You should see something like git version 2.47.1.

3

Tell Git who you are

Do this once on each computer. Copy all four lines and paste them together.

git config --global user.name "Your Name"
git config --global user.email "you@example.com"
git config --global init.defaultBranch main
git config --global core.editor nano

Your name and email go on every save (commit) you make. The last two lines name your main branch main and pick an editor that's easy to use.

Check your settings:

git config --global --list
4

Create your GitHub account

  1. Go to github.com/signup.
  2. Use an email you'll keep after college (not your college email if it expires).
  3. Pick a professional username: sitashrestha, not xXdarkLord99Xx. It goes on your CV.
  4. Use the same email as in step 3. Verify it, then type your username in the box at the top.
5

Connect to GitHub with an SSH key

GitHub doesn't accept your account password from the terminal. Instead you make an SSH key: a pair of files on your computer. GitHub gets the public half and recognises your computer from then on. Do this once per computer, in Git Bash.

a. Make the key. Press Enter for every question it asks.

ssh-keygen -t ed25519 -C "you@example.com"

b. Copy the public key.

cat ~/.ssh/id_ed25519.pub | clip

Nothing prints. The key is now on your clipboard.

pbcopy < ~/.ssh/id_ed25519.pub

Nothing prints. The key is now on your clipboard.

cat ~/.ssh/id_ed25519.pub

Select the whole line it prints (it starts with ssh-ed25519) and copy it.

c. Open github.com/settings/ssh/new, give it a title like "My laptop", paste the key and click Add SSH key.

d. Test it. Type yes if it asks "Are you sure you want to continue connecting?"

ssh -T git@github.com

You should see Hi your-username! You've successfully authenticated.

Only ever share the file ending in .pub. The other file is your private key: never paste it anywhere.

6

Push your first project

a. On GitHub, click + then New repository. Name it my-first-website. Leave "Add a README file" unticked. Click Create repository.

b. In your Git Bashterminal, run these lines:

mkdir my-first-website
cd my-first-website
echo "<h1>Namaste, I'm Your Name</h1>" > index.html
git init
git add index.html
git commit -m "Add my first webpage"
git remote add origin git@github.com:your-username/my-first-website.git
git push -u origin main

c. Refresh the GitHub page. Your index.html is there. You've pushed your first project.

7

Every day after that

Inside your project folder, after you change something:

git status
git add .
git commit -m "Say what you changed"
git push

status shows what changed. add picks the changes to save. commit saves them with a message. push sends them to GitHub.

8

Put it online (GitHub Pages)

Any repository with an index.html can become a free public website.

  1. On GitHub, open your repository, then Settings → Pages.
  2. Under "Branch", choose main and / (root), then Save.
  3. Wait a minute and refresh. Your site is live at:
https://your-username.github.io/my-first-website/

Every git push updates the site within a minute or two. The repository must be public on a free account.

Stuck?

Find your error message below. Still stuck? Show the trainer a photo of the full error.

'git' is not recognized, or git: command not found

Close every terminal window and open a new one. Old windows don't see newly installed programs.

Still failing? Use Git Bash, not Command Prompt. If it fails there too, run the installer again and keep the default choices.

Still failing? Git isn't installed yet. Go back to step 1.

Please tell me who you are / Author identity unknown

Git doesn't know your name and email yet. Do step 3, then run your git commit again.

A strange screen opened after git commit and I can't get out

That's an editor called Vim. Press Esc, type :wq and press Enter.

Next time, add the message in the command itself: git commit -m "your message". Step 3's last line also switches you to an easier editor.

Support for password authentication was removed

GitHub won't take your password in the terminal.

Do step 5, then point your project at the SSH address:

git remote set-url origin git@github.com:your-username/my-first-website.git
Permission denied (publickey)

GitHub doesn't have your key yet. Redo step 5, parts b and c, then test again with ssh -T git@github.com.

error: src refspec main does not match any

You haven't saved anything yet. Run git add . and git commit -m "First commit", then push again.

If your branch is called master, rename it first:

git branch -M main
Could not get lock /var/lib/dpkg/lock

Another program is installing updates. Wait 5 to 10 minutes and try again, or restart the computer.
