Git in one page

Git is the tool on your laptop that keeps save points (commits). GitHub is the website that hosts them online. Git is the engine, GitHub is the online home.

1 · Is Git installed?

git --version

A version number (e.g. git version 2.47.1) means you're ready. "git is not recognized" means it isn't installed.

2 · Install it (5–10 min, best done before class)

Windows: download from git-scm.com/download/win, accept the defaults, then open Git Bash.
macOS: xcode-select --install, or brew install git.
Linux: sudo apt update && sudo apt install git

3 · Tell Git who you are (once)

git config --global user.name "Your Name"
git config --global user.email "you@example.com"
git init                  # start tracking this folder
git status                # what changed? (run it whenever you're confused)
git add index.html        # put a file "in the box"
git commit -m "Add my first webpage"   # seal it with a message
git log --oneline         # see your save points
git clone <url>           # copy a repo from GitHub
git push / git pull       # send to / get from GitHub

Words you'll hear

Repository: a folder Git tracks · Commit: a saved snapshot with a message · Branch: a safe space to try changes · Merge: combine changes · Push / Pull: upload to / download from GitHub · Pull request: "please review my change and merge it".

Good commit messages finish the sentence "This commit will…": ✅ Add input validation to calculator · ❌ update, final final

Never commit secrets. Passwords and API keys go in a .env file listed in .gitignore. Bots scan GitHub for leaked keys within minutes.

Card C · find the 2 bugs

#include <stdio.h>

int main() {
    int n, sum = 0;
    printf("Enter n: ");
    scanf("%d", n);
    for (int i = 1; i < n; i++)
        sum += i;
    printf("Sum of 1 to %d = %d\n", n, sum);
    return 0;
}
Card C: hints, not answersAct as a patient C tutor. Task: Help me find the bugs in this program. Expectation: Don't give me the fixed code. Give me one hint per bug, and let me try first. Audience: A first-year student learning C. Context: It should print the sum of 1 to n. For n = 5 it should print 15. How: Numbered hints, under 80 words in total. [PASTE THE CODE]
Answers (try first!)

1. scanf("%d", n) should be scanf("%d", &n): scanf needs the address of n.
2. i < n should be i <= n. Otherwise n = 5 gives 10, not 15.

Power prompts

Hack 1 · Make it ask you firstBefore you answer, ask me the three questions whose answers would most change what you write. Wait for my replies.
Hack 2 · Let it write the promptDon't answer yet. Interview me one question at a time about [WHAT I NEED], then write me a single prompt I can paste into a fresh chat.
Hack 4 · Make it argue with youHere is my plan: [MY PLAN] Make the strongest case against it. Don't balance it. Then tell me which of your points I should take most seriously.

Hack 3 · Show, don't describe: paste two or three examples of what you want instead of "make it professional". Remove names and numbers first.

Three rounds: draft → name exactly what's wrong ("keep the analogy, the code is too advanced") → bank what worked ("write the prompt that would have produced this first time"). Correct, don't regenerate.

⭐ Tutor, not ghostwriter: save this oneI'm a first-year CSIT student learning [TOPIC]. Don't give me the answer. Teach me with the Socratic method: ask me one question at a time, wait for my reply, give a hint if I'm stuck, and only confirm the answer once I've reasoned it out myself. At the end, give me 3 practice problems slightly harder than this one.

Stay safe and honest

Before you paste anything, ask: "If this leaked, who gets hurt?"

🟢 Green: use freely. Your own practice code, public information, lecture topics.
🟠 Amber: redact first. Replace real details with [NAME], [PHONE], [CITIZENSHIP NO.]. Put them back yourself, outside the chat.
🔴 Red: never, in a personal account. Passwords, API keys, OTPs, other people's private data. If removing the sensitive part kills the task, it's red.

🔕 Turn off "use my chats for training" in every AI account. Paying for a personal plan buys speed, not privacy.

🔑 Leaked a password or API key? Change it or revoke it now, then delete the chat. Asking the AI to "forget" does nothing.

📦 AI suggested a package? Check it exists on pypi.org or npmjs.com first. AI sometimes invents package names, and attackers register them.

🕵️ Photos, voices and videos can be faked convincingly. Verify the source, not the pixels. A relative asking for money urgently and secretly? Call back on the number you already have.

✋ Attempt first, then AI. First year is when you build your skills. Disclose AI use when a reader would feel misled not knowing, and follow your teacher's rules.

Which tool, and a few terms

Learn the questions, not the names: Where does the work live? Where does it need to go?

If you need…Try
To understand, draft or debugChatGPT, Gemini, Claude
Long documents or careful analysisClaude, or any assistant with a large context window
Sources you can checkPerplexity, or your assistant's search mode
Answers from your notesNotebookLM: upload PDFs, get cited answers
Work in Gmail, Docs, SheetsGemini
Help while coding in VS CodeGitHub Copilot (free with the Student Pack)

Token: a piece of a word. Your limit is counted in tokens, and the whole chat is re-sent every message, so: one task, one chat.

Context window: how much text the model can consider at once: your prompt, the chat so far, attached files and its answer. Its working memory, not everything it was trained on.

Temperature: how random the output is. Low = focused and repeatable (code, facts, summaries). High = varied (names, ideas, stories).

Specialist models: general chat, coding, image, speech and "reasoning" models that think longer before answering. Match the model to the job.
