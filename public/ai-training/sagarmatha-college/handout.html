Git in one page

Git is a program on your laptop that keeps save points of your project, called commits. GitHub is the website where you put them online, so they're backed up and others can see them.

Install Git and connect it to GitHub →

Step by step for Windows, macOS and Linux, with commands you can copy.

 
git init                  # start tracking this folder
git status                # what changed? (run it whenever you're unsure)
git add index.html        # put a file "in the box"
git commit -m "Add my first webpage"   # seal it with a message
git log --oneline         # see your save points
git clone <url>           # copy a repo from GitHub
git push / git pull       # send to / get from GitHub

Words you'll hear

Repository (repo): a folder Git is tracking · Commit: one save point, with a message · Push: send your commits to GitHub · Pull: get the latest from GitHub · Clone: download a whole repo.

Good commit messages finish the sentence "This commit will…". Good: Add input check to calculator. Bad: update, final final.

Never commit passwords or API keys. Automated programs search GitHub for them within minutes.

TEACH: five things to tell AI

Treat AI like a person: a smart new classmate on their first day, very capable, but knows nothing about you. Whatever you don't tell it, it guesses.

TTask
What exactly should it do?
EExpectation
What does good look like? What must it never do?
AAudience
Who reads it? What do they know?
CContext
What can it not possibly guess?
HHow
What shape should it come back in?

In a hurry? AAA: Ask AI to Ask. Let AI ask you questions first: "Before you answer, ask me 3 questions about what I need." It stops guessing, and you answer.

Answers (try first!)

1. alt="My photo is missing its closing ", so the browser swallows the next lines into the alt text.
2. href="github.com/sita" needs https:// in front. Without it, the browser looks for a page on your own site.

More prompts that help

Make it ask you firstBefore you answer, ask me the three questions whose answers would most change what you write. Wait for my replies.
Let it write the prompt for youDon't answer yet. Interview me one question at a time about [WHAT I NEED], then write me a single prompt I can paste into a fresh chat.
Make it disagree with youHere is my plan: [MY PLAN] Make the strongest case against it. Don't balance it. Then tell me which of your points I should take most seriously.

Show an example: paste one or two examples of what you want instead of saying "make it professional". Remove names and numbers first.

Fix, don't restart: if the answer is close, say exactly what to keep and what to change ("keep the example, but the code is too advanced"). Pressing "regenerate" is just a new guess.

Tutor, not answer machine: save this oneI'm a first-year [BSc CSIT / BCA] student learning [TOPIC]. Don't give me the answer. Teach me by asking me questions: ask me one question at a time, wait for my reply, give a hint if I'm stuck, and only confirm the answer once I've reasoned it out myself. At the end, give me 3 practice problems slightly harder than this one.

Stay safe and honest

Before you paste anything, ask: "If this leaked, who gets hurt?"

Green: use freely. Your own practice code, public information, lecture topics.
Amber: hide the details first. Replace real details with [NAME], [PHONE], [CITIZENSHIP NO.]. Put them back yourself, outside the chat.
Red: never paste it. Passwords, API keys, OTPs, other people's private data. If removing the sensitive part kills the task, it's red.

Turn off "use my chats for training" in every AI app's settings.

Pasted a password or API key by mistake? Change it right away, then delete the chat. Asking the AI to "forget" does nothing.

AI told you to install a package? Check it really exists on pypi.org or npmjs.com first. AI sometimes makes up package names, and attackers create fake packages with those names.

Photos, voices and videos can be faked. Check who posted it first. A relative asks for money, urgently and secretly? Hang up and call back on the number you already have.

Try it yourself first, then ask AI. First year is when you build your skills. Tell your teacher when you used AI, and follow their rules.

Your 7-day challenge

Solve a real problem with AI, and put it online. At the end you'll have a public link to something you actually built.

Problem ideas: an udharo (credit) book for a local shop · a BS ↔ AD date converter · a class attendance tracker · an exam countdown and study planner · a bus fare calculator for your route.

Then keep going: free courses

  • GitHub Skills: short interactive Git and GitHub courses
  • Elements of AI: University of Helsinki, no coding needed
  • Kaggle Learn: short hands-on Python, ML and data courses
  • CS50's Introduction to AI with Python: Harvard, free, once you're comfortable with Python

Fundamentals still win: maths, C, data structures, clear writing. AI makes strong fundamentals stronger. It can't replace missing ones.

If you remember three things

1. Git saves it. GitHub shows it. Push every lab: your GitHub is your CV.
2. Tell AI what you need (TEACH). Its answer is always a first draft.
3. If this leaked, who gets hurt? And try it yourself first, then ask AI.
