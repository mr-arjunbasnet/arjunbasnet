The three exercises in detail

Exercise 1 · 16 min · laptops · slide 13

Set up Git, then make your first commit

The day before: post arjun-basnet.com.np/ai-training/sagarmatha-college/setup in the class group and ask everyone to do steps 1–3 (install, check, name and email) at home. This is the single biggest time saver.

Order on the slide and the setup page: 1 install Git → 2 git --version → 3 name and email → 4 GitHub account → 5 SSH key added to GitHub (same on every OS; Windows uses Git Bash) → 6 repo my-first-website and first push → refresh, change, commit and push again. macOS users start xcode-select --install first; it downloads for 5–15 minutes, so they create the GitHub account meanwhile.

Watch for: lab PCs without admin rights (pair them with a laptop owner) · "git is not recognized" (open a new terminal / Git Bash) · "Please tell me who you are" (step 3 skipped) · "src refspec main" (no commit yet) · "Permission denied (publickey)" or "password authentication was removed" (SSH key not added, step 5). All fixes are at the bottom of the setup page.

Fallback: anyone whose Git won't install creates index.html in the browser (Add file → Create new file → Commit changes) and finishes at home.

Exercise 2 · 6 min · pairs

Prompt battle: lazy vs TEACH

Steps (6 min): each pair picks a task card. Partner A sends a lazy one-liner, Partner B builds a full TEACH prompt with the TEACH builder on the handout (five boxes become one copyable prompt) and sends it in the same tool, and they compare.

Task cards: A · Explain a stuck topic (number systems, K-maps, loops, limits) · B · A 2-week study plan for first-semester exams · C · Debug the web page on slide 26 · D · An extension email to a teacher.

Card C answers: (1) alt="My photo is missing its closing quote, so the next lines vanish into the alt text; (2) href="github.com/sita" needs https://, otherwise the browser looks on your own site. The prompt asks for hints, not fixes, which previews "tutor, not answer machine".

Debrief question: "Which TEACH letter made the biggest difference?" Expect Audience and How. For card D, point out if the AI invented the teacher's name or a reason: that's the placeholder lesson.

Exercise 3 · 8 min · individual

Ship it: an AI-drafted profile README, committed live

Steps: GitHub → + → New repository named exactly their username, Public, "Add a README file" ticked → fill in the pink fields of the prompt (slide 35, or the handout) and press Copy → edit the draft and delete anything untrue → paste into README.md → Commit changes with a real message → open github.com/username.

Common problems: a repo name that doesn't match the username exactly (the profile won't show it), or AI inflating skills ("passionate full-stack developer"). Tell them to delete it. Honesty is the point.

Privacy: first name and college are their choice. No phone numbers on a public profile.

Fallback: no account yet → draft with AI, save it in their notes, commit tonight.

Finish: 2–3 volunteers read out their URL and you open it on the projector. Applause. This is the photo moment.

Game · 7 min · individual

AI or Not?

Flow: QR → name, email, optional roll or section → one image at a time, 10 seconds each, Real or AI → instant feedback with the clue → results with a per-image reveal. 100 points per correct answer plus up to 50 for speed. One game per email; a game can only be resumed on the phone that started it.

Fair play: the server hands out each image only when its clock starts, and the answer key is encrypted in the public repo. DevTools shows nothing useful.

Projector: open /leaderboard in a new tab (button on slide 31). It refreshes every 3 seconds and shows the join QR. Emails never appear.

Image pool: 8 real photos from Nepal (Pexels) and 8 AI images (Wikimedia Commons), all credited after each answer. A game draws 5 of each. To change it: src/lib/sagarmatha/images.ts explains the steps.

Preparation checklist

The week before

  • Ask the coordinator for the room's projector input (HDMI/USB-C) and Wi-Fi details
  • Ask whether students bring phones or laptops, and roughly how many attend
  • Check the facts list below, especially model names and the Student Pack offer
  • Send the coordinator arjun-basnet.com.np/sagarmatha to share in advance (the handout has the Git install steps)
  • Switch on saving (the Supabase steps above) and play one test game

The day before

  • Run the whole deck once, timing each part against the run sheet
  • Test both live demos: the GitHub loop, and lazy vs TEACH in one AI tool
  • Delete any old my-first-website repo on your GitHub so the terminal demo starts clean, and have a terminal open in an empty folder
  • Download a copy of the slides to a USB stick as a backup

30 minutes before

  • Open /ai-training/sagarmatha-college/slides in Chrome, press F for fullscreen and P for the presenter view. Open /leaderboard in a second tab
  • Log in to GitHub and one AI tool in separate tabs
  • Test the countdown beep at room volume
  • Write the Wi-Fi details and arjun-basnet.com.np/sagarmatha on the board

If things go wrong

No Wi-Fi

Students use mobile data. If nobody can connect, do Exercise 2 on paper (write both prompts, swap with a neighbour, critique using TEACH) and assign Exercises 1 and 3 as homework.

Running late

Cut in this order: slide 17 (who's who: one line), slide 9 (CV: one line), slide 32 (AI or Not debrief: one sentence), the quiz walk-through (show 2 of the 6), slide 36 (7-day challenge: point to the handout). Protect AI or Not and Exercise 3.

Running early

Extend the Exercise 2 debrief: 3 pairs read their best prompts aloud and the class names the weakest TEACH letter. Or take more volunteers in Exercise 3.

Quiet room

Use fingers and hands for every vote, never cold-calling. Pairs share before individuals. Praise the first volunteer warmly. First-years in Nepal are often shy in the first 20 minutes, so it gets easier.

Engagement design: why it's built this way

Something to do every 5–7 minutes

Poll → predict → demo → exercise → quiz → game → exercise → game → exercise → quiz. Nobody sits through more than about 7 minutes of talking.

Examples from their week

C labs, scanf bugs, TU exams, K-maps, "dal bhat power 24 hour", Messenger zip files. The course's office personas are swapped for student life.

Everything connects

Git commits → AI agents that open pull requests → API keys leaking on GitHub → an AI-drafted README committed with Git. One story, not two talks.

They leave with something real

A live GitHub profile they can show friends tonight is far more memorable than any slide.
